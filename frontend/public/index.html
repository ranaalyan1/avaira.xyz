01Pillars

Rating, clearing and underwriting in one request path.

Capital markets spread these three functions across three institutions. An agent needs all three at the moment it acts, which is why they live inside the same gate.

Rate

Score, recomputable by anyone

Six weighted inputs decide what an agent may attempt and how much collateral it posts. The formula is public, so two operators reading the same settled history reach the same grade.

Clear

Committed before, attested after

The envelope is hashed and committed before the action is attempted, then the outcome is attested against it. The protocol keeps its own record of what was authorised and what actually ran.

Insure

Underwriters stake against missions

Backers take a position on a mission. A failed mission pays them from slashed collateral on the 85, 10 and 5 split; a mission that settles returns principal plus its share of the fee.

02The gate

Four planes, passed in order.

Before any money moves the intent has to clear an envelope, a policy file, a prover and a permit. The gate either returns a signed permit or the code that says why it could not — there is no third outcome and no review queue.

01 Envelope
spend ceiling and allowed actions, declared by the agent
02 Commitment
the envelope hashed and committed before the attempt
03 Policy
versioned OPA Rego decides whether the action class is allowed
04 Prover
interval arithmetic over hard invariants, with a witness on failure
05 Permit
EIP-712 signature for this intent, this agent, this deadline, single use
06 Settlement
outcome attested, fee split, score updated from the result

02.3Refusals

Nine ways the gate says no, and one way it says yes.

A refusal is a value, not an outage. Every blocked intent carries the code for why, which makes the reason machine-readable for the agent, the operator and the underwriter at the same time.

ALLOWED
agent cleared to execute
UNKNOWN_AGENT
no identity is registered for this address
BANNED
terminal ban, no path back
SUSPENDED
slashed into suspension, waiting on collateral
STAKE_TOO_LOW
bond sits below the minimum the envelope requires
SCORE_TOO_LOW
Avaira Score under the floor the mission demands
INTENT_NOT_COMMITTED
no commitment matches the intent hash
INTENT_EXPIRED
the envelope deadline has passed
INTENT_ALREADY_EXECUTED
the intent is single use and was already attested
ENVELOPE_MISMATCH
the stored envelope does not match the committed hash

03Score engine

One number, six inputs, no discretion.

The score decides what an agent may attempt and how much collateral it has to post. It is arithmetic over settled outcomes, so two operators reading the same history get the same grade — and anyone can recompute it and challenge the result on chain.

05Integration

One call around the function that spends.

The integration point is the callable, not the model. Wrap the function that performs the action and the gate handles the envelope, the policy check, the permit and the audit entry. SDKs ship for TypeScript, Python and Rust, plus LangChain and CrewAI wrappers. 

from avaira import AvairaClient, AvairaConfig, RiskEnvelope

envelope = RiskEnvelope(max_spend_usd=50.0, allowed_actions=["search"])
avaira = AvairaClient(AvairaConfig(api_key="...", risk_envelope=envelope))

# execute_fn is only reached when the gate returns a signed permit
result = await avaira.run(
    task="Search for YC news",
    execute_fn=lambda: my_agent.run("Search for YC news"),
)

print(result["status"])   # "completed" or "blocked"

06Questions

Asked often enough to answer here.

How is this different from logging what an agent did?

Logging answers the question after the money has moved. The gate runs before it: the envelope, the policy file and the prover all have to agree, and without a signed permit the function that spends is never entered.

Does it care which model or framework the agent uses?

No. You wrap the callable that performs the action. The gate reasons about the intent, its target and its value, so any model that can call a function is compatible.

What happens when an agent deviates from its envelope?

The intent is refused with a reason code and enforcement follows the documented ladder: a recorded warning, then suspension with slashed collateral and a 24 hour cooldown, then a terminal ban. Underwriters are paid from the slashed bond.

What does the gate cost per check?

Nothing per check. The gate is not metered, never per intent or per agent. The protocol earns from settled activity and from slashing, not from sitting in the path.

Which chains does it support?

EVM chains. The contract set has addresses on Fuji and a Foundry deployment script for any EVM target, and identity follows ERC-8004 so the registry stays portable.
