Deviation detected

The intent is refused with its reason code. Suspension slashes collateral, freezes the agent and closes the credit line, and the pool is paid before the treasury is.

Defensibility

Nine ways the gate says no.

Committed before execution

An intent that was never committed cannot be executed, so there is no window in which an agent can act first and explain later.

Single-use permissions

A permit is bound to one intent hash and burns on use. Replaying an approved intent returns INTENT_ALREADY_EXECUTED.

Witnesses, not verdicts

When the prover refuses, it returns the interval that broke the invariant. A refusal is evidence a counterparty can read.

Score attached to collateral

The rating carries weight because it moves real money: grades set collateral ratios, and a slash moves the grade down.

Blast radius contained

The gate wraps the callable, not the model. It reasons about the intent, the target and the value, so the worst case is one refused call.

Revenue architecture

Four fee streams, all of them from settled activity.

Underwriting spread

5% of every settled mission, split across the backers.

Slashing share

20% of slashed collateral reaches the treasury; the rest compensates the pool.

Anchoring

Merkle roots committed on chain, batched across each agent's intents.

Data and scores

Per-query access to scores, refusal history and settlement records.

The protocol earns when a mission settles or when collateral is slashed, never for sitting in the path. There are no tiers and no per-check charge.

Developer experience

One call around the function that spends.

The integration point is the callable, not the model. Wrap the function that performs the action and the gate handles the envelope, the policy check, the permit and the audit entry.

from avaira import AvairaClient, AvairaConfig, RiskEnvelope

envelope = RiskEnvelope(max_spend_usd=50.0, allowed_actions=["search"])
avaira = AvairaClient(AvairaConfig(api_key="...", risk_envelope=envelope))

# execute_fn is only reached when the gate returns a signed permit
result = await avaira.run(
    task="Search for YC news",
    execute_fn=lambda: my_agent.run("Search for YC news"),
)

print(result["status"])   # "completed" or "blocked"
